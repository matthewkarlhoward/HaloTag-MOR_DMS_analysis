# Supplemental figure 8 — CryoEM data processing, μOR–buprenorphine–miniGo

Panels a–d (processing workflow, GSFSC and viewing-direction plots, local resolution, and
the model overlay against μOR–morphine, PDB 8EF6) all come from cryoSPARC and ChimeraX.
There is no repository code for this figure.

The refined coordinate file determined in this study is included as
`data/structures/raw/experimental/buprenorphine.pdb`; the comparison structures 8EF6 and
the 7TM reference are in the same directory. Maps and particle stacks are deposited with
the EMDB/PDB (see the paper's Data availability section).
